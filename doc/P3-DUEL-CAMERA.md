# P3a：双目标基础构图（test.8 开发方案）

用户已验收test.7：远距离朝向纠正、Root接触停步、疾跑临时释放朝向正常。

本轮实现主动锁定后的双目标构图；自动索敌不转动镜头。基础观察角按双方连线和侧角建立，计算两者AABB在镜头坐标系的投影后选择距离，默认玩家左、目标右。对视野角与宽高比取保守值，后撤距离设置上限，远目标或巨大生物不承诺全部入镜。

按游戏时间与partialTick计算指数平滑，鼠标允许有限角度微调并缓慢回归；普通移动参考更新后的基础镜头，视觉震动不参与移动坐标系。疾跑/瞄准/自由观察暂时让出镜头旋转并平滑回到普通偏移，恢复后重新构图。取消锁定保留最后观察方向、恢复普通距离；死亡/换世界/离开越肩重置。

复用越肩已有体积射线碰撞；普通/决斗基础镜头 → YSS技能轨道 → Camera震动 → 合并位移最终碰撞。只调整客户端相机，不改YSS动画或玩家位置。先用JSON与命令提供开关，之后再考虑完整设置界面。

验证：纯数学测试双目标投影、不同体型/宽高比、距离上限、角度跨界、按时间平滑；构建与产物检查。真实构图、墙边退让、光影、疾跑过渡与YSS轨道叠加由游戏实测验收，不把数学测试称为游戏测试。

权限MoLang、Caster Move进一步仲裁、命中震动与VFX目标接口继续待办。本轮不修改YSM，不提交YSS上游PR。

## 使用与配置

默认启用。R主动锁定后开始构图；附近自动攻击目标不触发构图。主手无需持剑才能使用镜头，角色朝向辅助仍按原有持剑规则。

- `/yesstevecamera duel off`：临时关闭自动构图，保留锁定、朝向及震动。
- `/yesstevecamera duel on`：恢复（仍受配置enabled总开关限制）。
- `/yesstevecamera status`：Duel为framing、framing (distance capped)、standby或disabled。
- `config/yesstevecamera/duel.json`，修改后 `/yesstevecamera reload`。reload恢复配置状态并按既有规则清理当前锁定。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| enabled | true | 构图总开关 |
| sideAngle | 35 | 偏离双方连线的水平侧角（度） |
| minDistance | 3.5 | 拟合时镜头至两者中心的最小后撤距离 |
| maxDistance | 12 | 镜头离玩家眼部的最大距离（格），不是锁定范围 |
| smoothSeconds | 0.3 | 指数平滑时间常数（秒） |
| mouseYawLimit | 20 | 鼠标水平微调上限（度） |
| mousePitchLimit | 12 | 鼠标俯仰微调上限（度） |

鼠标微调约1秒时间常数回归。疾跑、瞄准、自由观察、游泳、骑乘及飞行时停止自动旋转、逐渐恢复普通偏移；退出保持当前观察角，不突然跳回进入前角度。切世界/死亡/离开越肩清理过渡状态。

只使用实体碰撞箱估算体型，模型伸出碰撞箱的武器/特效不计入拟合。达到距离上限时优先保留玩家在画面左侧；墙体碰撞、较强技能旋转/缩放仍可能使一方暂时出画；不会为保证构图取消合法锁定。YSS轨道在基础构图之后按既有事件叠加，Camera最终裁剪合成后的位移；外部模组若在更晚阶段继续改相机，仍需单独兼容。

## 第三人称任意方向起跑

Minecraft原版通常要求先有W前进输入，才接受疾跑键。test.10在Camera的肩部第三人称输入阶段补齐这条限制：只要A/S/D/W任意方向有输入且按住疾跑键，就在`LocalPlayer.aiStep`末尾设置疾跑状态，因此第一帧也会按对应方向起跑。第一人称、界面、无方向输入、游泳、飞行、骑乘和旁观状态保持原版规则。

该逻辑只扩展“能否进入疾跑”，不改变锁定相对移动或意图式释放：锁定时W/S/A/D仍按目标坐标系转换；向目标疾跑保持构图，后退/横移或主动转头才释放本次辅助。

## 锁定移动与疾跑判定

锁定时移动输入转换到目标方向坐标系：W为朝目标、S为远离、A/D为相对目标横移，保持原输入强度，不修改实体速度。只在主动锁定且未进入自由观察/瞄准时接管输入。

疾跑不再一律释放构图。W或W+A/W+D等朝目标输入继续保持朝向与构图；S、纯A/D或镜头主动转离目标超过阈值时，本次疾跑进入逃跑状态，释放朝向和构图但保留锁定。结束疾跑后状态重置，下一次向目标疾跑可重新保持锁定。自动构图造成的角度变化不会被误当作玩家转头。

## 游戏验收

1. 开阔平地R锁定普通怪物，确认玩家偏左、目标偏右，接近/远离时距离平滑。
2. 鼠标小幅调整后松手，观察回归；切换目标、长按R取消不应突然反向旋转。
3. 锁定状态疾跑转身逃跑，应恢复自由观察；结束疾跑后重新构图。
4. 在墙边/低屋顶/窄走廊测试，优先避免穿墙；测试light_hit震动以及现有YSS镜头轨道叠加。
5. 大体型目标、高低差、极远目标、窄窗口、低帧率；达到12格上限可不完整入镜，但不丢锁。
6. 第三人称分别只按A、S、D再按疾跑，确认无需先按W即可起跑；第一人称对照应保持原版。
7. 锁定后按W/S/A/D，确认移动相对目标；W疾跑冲向目标保持构图，S或转身疾跑释放构图，结束疾跑后再次W可恢复。
8. 切第一人称、重新进入越肩、退出世界重进，不能残留旧目标的镜头状态。

自动化只验证数学投影、边界与构建，不替代上述实机验收。
